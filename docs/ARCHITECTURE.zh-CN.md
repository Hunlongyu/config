头文件库不需要 src 目录。移除全局默认 Store、可变策略注册表和永久保留引用的缓存。

## 状态与事务

提交快照包含可写数据、合并后的文件层、环境采样、有效视图、来源字节、版本与 dirty 状态。读取仅在短暂共享锁下取得快照句柄，类型转换在锁外进行。

三个 get 重载共用一次路径解析和快照读取。缺失回退函数与 update 回调直接以模板接收，允许只能移动的捕获；同步执行一次，不保存回调。回退不会写入配置，也不会因并发提交重新读取或重试。长期保存的订阅、校验和监视回调仍由其所有者管理生命周期。

find 在判断存在性和转换期间持有同一份快照。get/find 拒绝直接返回借用类型，标量数值在转换前检查边界；普通容器和自定义反序列化器保留各自的成员转换契约。与键相关的错误包含原始指针。可写层不存在的 erase 在校验和提交前返回 false，保持版本、dirty 和存储不变。

写入在锁外准备候选并校验。提交时由写锁串行执行版本检查、可选持久化及发布；版本变化报 conflict，不覆盖新状态。用户修改函数不会自动重试。save 先取得同一把写锁，再读取快照。

自动修改持久化后发布。手动修改提交内存并标记 dirty。显式 reload 可以替换未保存的可写修改，后台 reload 则拒绝丢弃它们。只有成功提交才确认来源字节，失败版本继续重试。

事件按提交顺序排队，在状态锁、写锁之外派发。订阅句柄持有回调槽，Store 仅跟踪弱句柄。关闭 Store 会使已有句柄失效，回调捕获对象在观察者锁外析构。回调重入修改只追加事件，不递归派发。

## 文件与所有权

路径归一化处理绝对路径和已有符号链接。同一链接程序映像内，等价路径、已有硬链接和 Windows 大小写别名不能分别取得写入所有权。所有权条目使用弱引用并自动失效。

这不是跨进程锁，也不协调独立链接的多个 DLL 副本。多进程应用需自行协调所有权；任意外部写入仍可能与显式 save 竞争。监视器负责重载，不提供分布式事务。

默认后端先序列化完整内容，再创建唯一的同目录临时文件，完整写入并关闭后替换目标。失败只删除自己创建的临时文件，保留旧目标。保证正常文件系统操作下的完整文件替换，不宣称断电持久性，也不保证保留全部平台 ACL/元数据。

## 测试

每个用例使用独立临时目录，不删除真实应用数据目录。按行为组织：

| 测试组 | 验收内容 |
|---|---|
| store | 类型、结构体、三个 get 重载、回调次数与异常、移动捕获、严格路径、视图校验、根对象修改、路径别名所有权。 |
| reads | 返回类型与回退的编译期约束、标量数值边界、可选查询、拥有数据的结果、结构化键错误、并发写入时的快照寿命。 |
| persistence | 自动失败回滚、手动 dirty、缺失键删除无副作用、删除失败回滚、损坏文件、序列化/写入故障、Unicode 路径、编码迁移。 |
| sources | 来源优先级、读取视图一致性、环境隔离、统一解码、所有入口校验。 |
| subscriptions | 全部修改入口事件、顺序、重入、退订、异常与析构。 |
| concurrency | 可控保存交错、过期重载及删除拒绝、回退期间并发写入、单次更新、并行累加准确值。 |
| watcher | 相同时间戳变化、重试、冲突、dirty 保护、取消与生命周期。 |
| consumers | 公共头独立编译、多翻译单元、宿主依赖复用、安装包与手动集成。 |
| examples / docs | 编译运行示例，核对 README 与示例源代码同步，检查本地链接。 |

并发回归在第一次后端写入时设置屏障，再启动第二次修改和保存。测试另生成一份仅移除 save 串行锁的头文件副本，要求同一回归必须失败。CTest 将成功拒绝该副本视为变异测试通过。这验证测试能约束保护措施，不代表覆盖率百分比。

CI 配置 Windows、Linux、macOS 构建测试，以及 Linux ASan/UBSan。Windows 本地可启用 CONFIG_SANITIZER。CI 覆盖率报告用于辅助诊断，不替代行为断言和变异测试。本机执行不证明其他操作系统或断电恢复行为。
